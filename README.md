# 2026-0129_ProyectoFinal_CSharp
#### Este es el proyecto final de la materia Lenguaje de Programacion 1, donde se utilizara el lenguaje C#,herramientas como Entitity framework, SQL Server, y proyectos como ASP.NET MVC

El proyecto consta de un CRUD de personas  siguiendo los principios SOLID,  donde se implementa un log-in, con validacion de diferentes usuarios, responsabilidades y niveles de acceso, creacion de reportes, manipulacion de Queries.
